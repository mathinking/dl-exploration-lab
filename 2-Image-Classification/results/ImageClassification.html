Image Classification with Convolutional Neural Networks

This example shows how to build, train, and evaluate convolutional neural networks (CNNs) for image classification using MATLAB. Starting from a minimal single-layer CNN and progressively improving the architecture, you will see how design choices — learning rate, depth, batch normalization, and pooling — affect classification accuracy.
The example uses the built-in handwritten digit dataset (10 classes, 28×28 grayscale images) and covers:
  1. Loading and splitting image data with imageDatastore.
  2. Defining a minimal CNN with a single convolution layer.
  3. Tuning the learning rate to understand its impact on convergence.
  4. Building a deeper CNN with multiple convolution blocks, batch normalization, and max pooling.
  5. Evaluating accuracy and visualizing predictions.

Load Image Data

Load the digit sample data as an image datastore. The imageDatastore function automatically labels the images based on folder names. The dataset has 10 classes (digits 0–9), and each image is 28×28×1 pixels.
dataFolder = fullfile(toolboxdir("nnet"), "nndemos", "nndatasets", "DigitDataset");
 
imds = imageDatastore(dataFolder, ...
IncludeSubfolders=true, ...
LabelSource="foldernames");
 
classNames = categories(imds.Labels);
Partition the data into training, validation, and test data sets. Use 70% of the images for training, 15% for validation, and 15% for testing. Specify "randomized" to assign the specified proportion of files from each class to the new data sets. The splitEachLabel function splits the image datastore into three new datastores.
[imdsTrain, imdsValidation, imdsTest] = splitEachLabel(imds, 0.7, 0.15, 0.15, "randomized");
Preview a few training images to get a sense of the data.
figure
tiledlayout("flow")
perm = randperm(numel(imdsTrain.Files), 16);
for i = 1:16
nexttile
img = readimage(imdsTrain, perm(i));
imshow(img)
title(string(imdsTrain.Labels(perm(i))))
end
sgtitle("Sample Training Images")

Approach 1: Minimal CNN

Start with the simplest possible CNN — a single convolution layer followed by ReLU activation, a fully connected output layer, and softmax. This serves as a baseline to understand the fundamental building blocks.

Define Network Architecture

To build the network, use the Deep Network Designer app.
deepNetworkDesigner
To create a blank network, pause on Blank Network and click New.
In the Designer pane, define the convolutional neural network architecture. Drag layers from the Layer Library and connect them. To quickly search for layers, use the Filter layers search box in the Layer Library pane. To edit the properties of a layer, click the layer and edit the values in the Properties pane.
Drag these layers in order and connect them sequentially. First, drag an imageInputLayer onto the canvas and set InputSize to 28,28,1.
Next, drag these layers onto the canvas and connect them in order:
  • convolution2dLayer
  • batchNormalizationLayer
  • reluLayer
Then, connect a fullyConnectedLayer and set OutputSize to the number of classes in the data, in this example, 10.
Finally, add a softmaxLayer.
To check that the network is ready for training, click Analyze. The Deep Learning Network Analyzer reports zero errors or warnings, so the network is ready for training. To export the network, click Export. The app saves the network as the variable net_1.

Create Architecture without DND

net_1 = [...
imageInputLayer([28 28 1]), ...
convolution2dLayer(3, 32), ...
reluLayer, ...
fullyConnectedLayer(10), ...
softmaxLayer];

Train and Evaluate the Minimal CNN

Specify the training options. Choosing among the options requires empirical analysis. To explore different training option configurations by running experiments, you can use the Experiment Manager app.
options = trainingOptions("sgdm", ...
MaxEpochs=20, ...
ValidationData=imdsValidation, ...
ValidationFrequency=30, ...
Plots="training-progress", ...
Metrics="accuracy", ...
Verbose=false, ...
InitialLearnRate = 0.0001);

Train Neural Network

Train the neural network using the trainnet function. Because the aim is classification, use cross-entropy loss.
net = trainnet(imdsTrain,net_1,"crossentropy",options);

Test Neural Network

Test the neural network using the testnet function. For single-label classification, evaluate the accuracy. The accuracy is the percentage of correct predictions. By default, the testnet function uses a GPU if one is available. To select the execution environment manually, use the ExecutionEnvironment argument of the testnet function.
accuracy = testnet(net,imdsTest,"accuracy")
accuracy = 96.1333

Fine Tuning 1: Change Learning Rate and Train

The network we train tries to minimize a loss function by using an algorithm called gradient descent. The learning rate contributes to whether we can minimize that function.
  • Too high - the loss function never converges to a minimum. This is what happened when we used the default learning rate.
  • Too low - the loss function converges on a local minima.
Change the learning rate above by selecting a different value from the drop down menu. Observe the change in the accuracy

Fine Tuning 2: Improve Network Architecture and Train

Improving the network architecture can increase training accuracy. This time, we will try a more sophisticated network architecture. This network has multiple convolution layers, as well as batch normalization layers, which improve the quality and convergence rate of the training.
net_2 = [
imageInputLayer([28 28 1])
 
convolution2dLayer(3, 32)
batchNormalizationLayer
reluLayer
maxPooling2dLayer(5)
 
convolution2dLayer(3, 64)
batchNormalizationLayer
reluLayer
maxPooling2dLayer(5)
 
fullyConnectedLayer(10)
softmaxLayer];
 
options = trainingOptions("sgdm", ...
MaxEpochs=20, ...
ValidationData=imdsValidation, ...
ValidationFrequency=30, ...
Plots="training-progress", ...
Metrics="accuracy", ...
Verbose=false, ...
InitialLearnRate = 0.0001);
 
netnew = trainnet(imdsTrain, net_2, "crossentropy", options);
accuracy = testnet(netnew,imdsTest,"accuracy")
accuracy = 99.2667

Food for thought

Changing the network architecture definitely had an impact of the accuracy but at the same time size of the network increased significantly. Is the improvement worth the increase in size?

Make Predictions

Make predictions using the minibatchpredict function and convert the scores to labels using the scores2label function. By default, the minibatchpredict function uses a GPU if one is available.
scores = minibatchpredict(net,imdsTest);
YPred = scores2label(scores,classNames);
Visualize a random sample of predictions alongside the true labels.
numTestObservations = numel(imdsTest.Files);

Next Steps

  • Increase depth and epochs — add more convolution blocks and train longer for higher accuracy.
  • Data augmentation — use imageDataAugmenter to apply random rotations, translations, and scaling during training, improving robustness.
  • Transfer learning — start from a pre-trained network (e.g., ResNet, GoogLeNet) and fine-tune it on your dataset. This is especially powerful when you have limited training data.
  • Experiment Manager — use the Experiment Manager app to systematically sweep hyperparameters and compare results.
